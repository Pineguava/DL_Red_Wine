# Project Overview
### This project trains a Multi-Layer Perceptron (MLP) neural network on the UCI Red Wine Quality Dataset to predict the quality score (scale 0–10) of wine using 11 measurable chemical attributes.
##Key Results
 - Test Mean Absolute Error (MAE): ~0.53 quality points
 - Baseline MAE (Mean Predictor): ~0.70 quality points
 - Relative Improvement: ~25% over baseline

On average, the model's predictions deviate by only ~0.5 points from expert sommelier ratings.
